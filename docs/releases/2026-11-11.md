## Separate reproducibility and presentation update

- A hash-locked Python 3.14.4 Windows environment covers application and test
  dependencies. It retains pandas 3.0.2, NumPy 2.4.4 and Streamlit 1.56.0 from
  the reviewed environment. The broader requirement files remain available,
  but only the lock is used for repeatable installation and CI.
- GitHub Actions runs the offline regression and dashboard tests on Windows.
  Tests use synthetic fixtures and temporary outputs, require no source API
  credentials, and reject live Requests HTTP calls.
- The dashboard labels loaded completeness/confidence values as saved coverage.
  It explains that the separately reviewed 4 High / 29 Good / 62 Moderate
  assessment is a dated result, not an automatic replacement of loaded metadata.
- The final research PDF is available directly in the dashboard, even when no
  saved county tables are installed. Any historical model report is identified
  separately. Exported county briefs include the coverage caveat.

This follow-up does not change scoring code, source collectors, input files,
numeric outputs, or the final report. No dataset refresh, production deployment
or predictive validation is implied. Candidate NOAA and SVI analyses remain
outside the scores. No further email outreach is planned.

See [reproducibility instructions](../reproducibility.md) for installation,
verification, dashboard data handling and dependency-update procedures.

## Local verification

On November 11, the locked Windows/Python environment installed successfully,
`pip check` found no broken requirements, and all 42 tests passed. Existing
pandas fragmentation warnings remain; no scoring refactor is included.
Streamlit AppTest loaded an isolated copy of the saved outputs without exceptions
(26 tabs, including nested tabs, and 23 metrics). Browser inspection confirmed
the coverage notice and separate final/historical report downloads.

All 340 original/frozen file hashes and 117 copied output hashes matched the
preservation manifest. Scoring modules, pipeline, frozen regression fixtures and
the final report have no changes. These are local verification results; hosted
CI results are recorded separately on the pull request.

The first clean-runner check exposed a synthetic ACS test's dependency on a
local Census credential. That test now explicitly supplies a dummy key alongside
its mocked response; no collector logic or real credentials are changed.
